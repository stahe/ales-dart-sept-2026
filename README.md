# Introducción al lenguaje Dart mediante ejemplos

> ⚠️ **Este repositorio no es un proyecto de software.** No hay ninguna aplicación que instalar, ningún paquete que publicar ni problemas de código que corregir: se trata de **material de curso**, escrito para estudiantes que aprenden el lenguaje Dart.

## 📖 Lea el curso

El curso puede leerse en línea en esta dirección:

**👉 [https://stahe.github.io/ales-dart-sept-2026/](https://stahe.github.io/ales-dart-sept-2026/)**

No se requiere ninguna instalación para leerlo: basta con un navegador.

## 🎯 ¿A quién está dirigido este curso?

Este curso está dirigido a estudiantes que **no tienen conocimientos previos** del lenguaje Dart.
Está concebido bajo el mismo principio que el curso *Introducción al lenguaje TypeScript y al framework web NestJS mediante ejemplos*: aprender un lenguaje a través de una serie de pequeños scripts independientes, comentados línea por línea, en lugar de una explicación teórica de su gramática. La estructura del curso sigue la del curso paso a paso de TypeScript, con un script Dart junto a cada script TypeScript, para permitir una comparación directa de cómo cada lenguaje responde a la misma necesidad.

## 📚 Esquema del curso

El curso está organizado en grandes secciones:

1. **Configuración del entorno de desarrollo** — verificación de las herramientas, configuración del proyecto en VS Code, primer script, análisis estático, linter y la extensión de Dart.
2. **Fundamentos de Dart** — conceptos básicos del lenguaje, arreglos, objetos,
   cadenas, expresiones regulares, funciones, errores y
   excepciones, módulos, programación orientada a eventos y funciones asíncronas,
   clases y novedades de Dart 3.x (records, patrones, clases selladas).
3. **Instalación de un servidor NestJS** — el servidor de cálculo del impuesto sobre la renta,
   tomado directamente del curso de TypeScript: sirve como objetivo real para probar las funciones HTTP de Dart,
   del mismo modo que sirve como objetivo para los clientes HTTP del curso original. (Los capítulos que enseñan NestJS en sí se omiten aquí a propósito: es un
   tema que no está directamente relacionado con el aprendizaje del lenguaje Dart.)
4. **Funciones HTTP de Dart y clientes del servicio de cálculo del impuesto** — cuatro
   variantes de cliente para el mismo servidor: un script CLI sencillo, capas DAO/negocio separadas,
   un proyecto compilado y, por último, una aplicación web completa con interfaz HTML.
5. **Acceso a bases de datos** — el controlador nativo de MySQL, seguido de un “ORM ligero” escrito a mano, ya que no existe un equivalente maduro de TypeORM o Prisma para Dart.
