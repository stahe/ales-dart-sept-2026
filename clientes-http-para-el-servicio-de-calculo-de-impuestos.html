Los cuatro se apoyan en el mismo servidor NestJS, instalado en el capítulo anterior.

    // dao1.dart
// Porta Dao1.ts: la capa [dao] (Data Access Object) encapsula todos los
// detalles de la comunicación HTTP con el servidor de cálculo de impuestos (URL,
// método, cookie de sesión) detrás de métodos de negocio simples
// (initSession, authenticateUser, calculateTax...).
import 'package:dio/dio.dart';

class Dao1 {
  final Dio _dio;
  final String _sessionCookieName;
  String _sessionCookie = '';

  // constructor - recibe la instancia de Dio a utilizar, como el script de TypeScript
  // recibía la instancia de axios como parámetro
  Dao1(this._dio) : _sessionCookieName = "connect.sid";

  // inicio de sesión
  Future<dynamic> initSession() {
    return _getRemoteData(
      'main.php',
      method: 'GET',
      queryParameters: {'action': 'init-session', 'type': 'json'},
    );
  }

  Future<dynamic> authenticateUser(String user, String password) {
    return _getRemoteData(
      'main.php',
      method: 'POST',
      queryParameters: {'action': 'authenticate-user'},
      data: {'user': user, 'password': password},
      contentType: Headers.formUrlEncodedContentType,
    );
  }

  // cálculo del impuesto
  Future<dynamic> calculateTax(String married, int children, int salary) {
    return _getRemoteData(
      'main.php',
      method: 'POST',
      queryParameters: {'action': 'calculate-tax'},
      data: {'married': married, 'children': children, 'salary': salary},
      contentType: Headers.formUrlEncodedContentType,
    );
  }

  // lista de simulaciones
  Future<dynamic> listSimulations() {
    return _getRemoteData(
      'main.php',
      method: 'GET',
      queryParameters: {'action': 'list-simulations'},
    );
  }

  // eliminar una simulación
  Future<dynamic> deleteSimulation(int index) {
    return _getRemoteData(
      'main.php',
      method: 'GET',
      queryParameters: {'action': 'delete-simulation', 'number': index},
    );
  }

  Future<dynamic> _getRemoteData(
    String path, {
    required String method,
    Map<String, dynamic>? queryParameters,
    Object? data,
    String? contentType,
  }) async {
    // para la cookie de sesión
    final options = Options(
      method: method,
      contentType: contentType,
      headers: {'Cookie': _sessionCookie},
      validateStatus: (_) => true,
    );
    // ejecución de la solicitud HTTP
    final response = await _dio.request(
      path,
      queryParameters: queryParameters,
      data: data,
      options: options,
    );
    // recuperamos la cookie de sesión si existe
    final setCookie = response.headers['set-cookie'];
    if (setCookie != null) {
      for (final header in setCookie) {
        final result = RegExp('^($_sessionCookieName.+?);').firstMatch(header);
        if (result != null) {
          _sessionCookie = result.group(1)!;
          break;
        }
      }
    }
    // la respuesta del servidor está en [response.data]
    return response.data;
  }
}

    Comentemos este código:

    • Línea 48: La capa [dao] (Data Access Object) encapsula todos los detalles de la comunicación HTTP (URL, método, cookie de sesión) detrás de métodos de negocio simples: [initSession], [authenticateUser], [calculateTax], [listSimulations], [deleteSimulation] (línea 57).
    • Línea 15: [Dao1(this._dio)] recibe como parámetro del constructor la instancia de [Dio] que se va a usar, exactamente como el script de TypeScript recibía la instancia de [axios].
    • Línea 65: [_getRemoteData] (privado, prefijo [_]) centraliza el seguimiento manual de la cookie de sesión ([response.headers['set-cookie']], [RegExp] (línea 90)) ya visto en dart_dio_03.dart: cada método público del DAO se apoya en este mismo método privado.

    log("-----------authenticate-user");

    log(response);
  } catch (error) {
    // registramos el error en el log
    print("error=$error");
  }
}

    // business.dart
// Porta Business.ts: el cálculo del impuesto, realizado íntegramente del lado del cliente
// (en el navegador en TypeScript, aquí en el programa Dart), a partir de
// los datos fiscales en bruto obtenidos una sola vez del servidor mediante
// [Dao2.getAdminData] (ver dao2.dart).
class Business {
  // [dynamic]: la estructura exacta de los datos enviados por el servidor
  // de impuestos (tasas, topes...) no está documentada aquí; como en
  // TypeScript, nos mantenemos deliberadamente flexibles con este tipo
  final Map<String, dynamic> taxAdminData;

  Business(this.taxAdminData);

  // cálculo del impuesto
  // --------------------------------------------------------------------------
  // married: sí, no
  // children: número de hijos
  // salary: salario anual
  Map<String, dynamic> calculateTax(String married, int children, num salary) {
    // cálculo del impuesto con hijos
    final result1 = _calculateTax2(married, children, salary);
    final tax1 = result1['tax'] as num;
    // cálculo del impuesto sin los hijos
    Map<String, dynamic> result2;
    num tax2;
    num halfShareCeiling;
    if (children != 0) {
      result2 = _calculateTax2(married, 0, salary);
      tax2 = result2['tax'] as num;
      // aplicación del tope del cociente familiar
      halfShareCeiling = taxAdminData['halfShareQfCeiling'] as num;
      if (children < 3) {
        // halfShareCeiling para los 2 primeros hijos
        tax2 = tax2 - children * halfShareCeiling;
      } else {
        // halfShareCeiling para los 2 primeros hijos, el doble para los siguientes
        tax2 = tax2 - 2 * halfShareCeiling - (children - 2) * 2 * halfShareCeiling;
      }
    } else {
      // sin nuevo cálculo del impuesto
      tax2 = tax1;
      result2 = result1;
    }
    // tomamos el mayor impuesto entre [tax1, tax2]
    num tax;
    num rate;
    num surcharge;
    if (tax1 > tax2) {
      tax = tax1;
      rate = result1['rate'] as num;
      surcharge = result1['surcharge'] as num;
    } else {
      surcharge = tax2 - tax1 + (result2['surcharge'] as num);
      tax = tax2;
      rate = result2['rate'] as num;
    }
    // cálculo de un posible descuento
    final discount = _getDiscount(married, tax);
    tax -= discount;
    // cálculo de una posible reducción de impuesto
    final reduction = _getReduction(married, salary, children, tax);
    tax -= reduction;
    // resultado
    return {
      'tax': tax.floor(),
      'surcharge': surcharge,
      'discount': discount,
      'reduction': reduction,
      'rate': rate,
    };
  }

  // --------------------------------------------------------------------------
  Map<String, dynamic> _calculateTax2(String married, int children, num salary) {
    // número de partes
    married = married.toLowerCase();
    num shares;
    if (married == "yes") {
      shares = children / 2 + 2;
    } else {
      shares = children / 2 + 1;
    }
    // 1 parte por hijo a partir del 3.º
    if (children >= 3) {
      // media parte adicional por cada hijo a partir del 3.º
      shares += 0.5 * (children - 2);
    }
    // ingreso imponible
    final taxableIncome = _getTaxableIncome(salary);
    // recargo
    num surcharge = (taxableIncome - 0.9 * salary).floor();
    // por problemas de redondeo
    if (surcharge < 0) {
      surcharge = 0;
    }
    // cociente familiar
    final quotient = taxableIncome / shares;
    // cálculo del impuesto
    final List<num> limits = List<num>.from(taxAdminData['limits'] as List);
    final List<num> coeffR = List<num>.from(taxAdminData['coeffR'] as List);
    final List<num> coeffN = List<num>.from(taxAdminData['coeffN'] as List);
    // se coloca al final de la lista [limits] para detener el bucle siguiente
    limits[limits.length - 1] = quotient;
    // búsqueda de la tasa de impuesto
    var i = 0;
    while (quotient > limits[i]) {
      i++;
    }
    // como colocamos quotient al final de limits, el bucle anterior
    // no puede salirse de la lista limits
    // ahora podemos calcular el impuesto
    final tax = (taxableIncome * coeffR[i] - shares * coeffN[i]).floor();
    // resultado
    return {'tax': tax, 'surcharge': surcharge, 'rate': coeffR[i]};
  }

  // taxableIncome = annualSalary - allowance (la deducción tiene un mínimo y un máximo)
  num _getTaxableIncome(num salary) {
    // deducción del 10% del salario
    num allowance = 0.1 * salary;
    // esta deducción no puede exceder tenPercentAllowanceMax
    final allowanceMax = taxAdminData['tenPercentAllowanceMax'] as num;
    if (allowance > allowanceMax) {
      allowance = allowanceMax;
    }
    // la deducción no puede ser inferior a tenPercentAllowanceMin
    final allowanceMin = taxAdminData['tenPercentAllowanceMin'] as num;
    if (allowance < allowanceMin) {
      allowance = allowanceMin;
    }
    // ingreso imponible
    final taxableIncome = salary - allowance;
    return taxableIncome.floor();
  }

  // calcula un posible descuento
  num _getDiscount(String married, num taxes) {
    // inicialmente, un descuento nulo
    num discount = 0;
    // monto máximo del impuesto para obtener el descuento
    final taxCeilingForDiscount = married == "yes"
        ? taxAdminData['coupleTaxCeilingForDiscount'] as num
        : taxAdminData['singleTaxCeilingForDiscount'] as num;
    if (taxes < taxCeilingForDiscount) {
      // monto máximo del descuento
      final discountCeiling = married == "yes"
          ? taxAdminData['coupleDiscountCeiling'] as num
          : taxAdminData['singleDiscountCeiling'] as num;
      // descuento teórico
      discount = discountCeiling - 0.75 * taxes;
      // el descuento no puede exceder el monto del impuesto
      if (discount > taxes) {
        discount = taxes;
      }
      // ningún descuento < 0
      if (discount < 0) {
        discount = 0;
      }
    }
    // resultado - ceil() es el equivalente en Dart de Math.ceil()
    return discount.ceil();
  }

  // calcula una posible reducción
  num _getReduction(String married, num salary, int children, num taxes) {
    // el tope de ingresos para tener derecho a la reducción del 20%
    num incomeCeilingForReduction = married == "yes"
        ? taxAdminData['coupleIncomeCeilingForReduction'] as num
        : taxAdminData['singleIncomeCeilingForReduction'] as num;
    final halfShareReductionValue = taxAdminData['halfShareReductionValue'] as num;
    incomeCeilingForReduction += children * halfShareReductionValue;
    if (children > 2) {
      incomeCeilingForReduction += (children - 2) * halfShareReductionValue;
    }
    // ingreso imponible
    final taxableIncome = _getTaxableIncome(salary);
    // reducción
    num reduction = 0;
    if (taxableIncome < incomeCeilingForReduction) {
      // reducción del 20%
      reduction = 0.2 * taxes;
    }
    return reduction.ceil();
  }
}

    Analicemos este código:

    • línea 12: [Business(this.taxAdminData)]: el constructor recibe los datos fiscales en bruto recuperados por el DAO una sola vez; después ya no se requieren más llamadas de red para calcular un impuesto.
    • línea 19: [Map<String, dynamic> calculateTax(String married, int children, num salary)]: una adaptación fiel, línea por línea, del algoritmo de TypeScript; los mismos pasos ([_calculateTax2], [_getTaxableIncome], [_getDiscount], [_getReduction]), la misma lógica para limitar el cociente familiar.
    • [.floor()]/[.ceil()] (métodos de [num]) reemplazan a [Math.floor(...)]/[Math.ceil(...)]: en Dart son métodos de instancia del propio número, no métodos estáticos de una clase utilitaria.
    • Las CLAVES del [Map] devuelto ([tax], [surcharge], [discount], [reduction]...) tienen los mismos nombres ASCII simples que los IDENTIFICADORES de Dart (nombres de variables y parámetros); una cadena puede contener acentos en Dart, pero un identificador no (vea simulation.dart, más adelante en este capítulo).

// Porta tax client/http client 3/src/Dao3.ts.
//
// Diferencia con dao2.dart: este archivo está pensado para compilarse para el
// NAVEGADOR (con `dart compile js`, ver el README de esta carpeta), no para
// ejecutarse en la CLI con `dart run`. En un navegador, la COOKIE DE SESIÓN
// la maneja automáticamente el propio navegador (como en cualquier

// el seguimiento MANUAL de cookies hecho a mano en dao1.dart/dao2.dart

// [mapping with TypeScript] "axios.defaults.withCredentials = true"
// (definido en main3.dart, no aquí) corresponde, del lado del paquete [http] de Dart, a
// la opción [withCredentials] del cliente específico para la web,
// [BrowserClient] (package:http/browser_client.dart) - una clase que
// existe SOLO cuando el código se compila para la web, a diferencia de
// http.Client, que funciona en todas partes.
import 'dart:convert';
import 'package:http/http.dart' as http;

class Dao3 {
  final http.Client _client;
  final String _baseUrl;

  Dao3(this._client, this._baseUrl);

  Future<dynamic> initSession() {
    return _getRemoteData(
      'main.php',
      method: 'GET',
      queryParameters: {'action': 'init-session', 'type': 'json'},
    );
  }

  Future<dynamic> authenticateUser(String user, String password) {
    return _getRemoteData(
      'main.php',
      method: 'POST',
      queryParameters: {'action': 'authenticate-user'},
      body: {'user': user, 'password': password},
    );
  }

  Future<dynamic> getAdminData() {
    return _getRemoteData(
      'main.php',
      method: 'GET',
      queryParameters: {'action': 'get-admindata'},
    );
  }

  Future<dynamic> _getRemoteData(
    String path, {
    required String method,
    Map<String, dynamic>? queryParameters,
    Map<String, String>? body,
  }) async {
    final uri = Uri.parse('$_baseUrl/$path').replace(
      queryParameters: queryParameters?.map((k, v) => MapEntry(k, '$v')),
    );
    final http.Response response;
    if (method == 'POST') {
      response = await _client.post(uri, body: body);
    } else {
      response = await _client.get(uri);
    }
    // [difference with the CLI client] ninguna lectura manual del encabezado
    // set-cookie aquí: en un navegador, response.headers ni siquiera lo expone
    // (encabezado protegido por el navegador, invisible para el
    // código JavaScript/Dart, precisamente porque ya lo maneja el propio navegador)
    return jsonDecode(response.body);
  }

// [technical choice] aquí usamos [package:web] (pub.dev/packages/web),

// .textContent, .addEventListener...). Una diferencia superficial que
// conviene conocer: un manejador de eventos de Dart (una función simple) debe

// entre el mundo Dart y el mundo JavaScript, hecho explícito, mientras que
// TypeScript no necesita ninguna conversión (allí todo ya es

// callbacks de la vista [authentication] - [difference with TypeScript]
// una interfaz de callbacks de TypeScript se traduce naturalmente en un
// RECORD de funciones en Dart (ver simulation.dart): más ligero que una
// clase, para un simple grupo de funciones
typedef AuthenticationCallbacks = ({void Function(String user, String password) onSubmit});

typedef CalculationCallbacks = ({
  void Function(String married, int children, int salary) onSubmit,
  void Function() onList,
  void Function() onEndSession,
});

typedef ListCallbacks = ({
  void Function(int number) onDelete,
  void Function() onCalculation,
  void Function() onEndSession,

class Views {
  final web.HTMLElement root;
  late web.HTMLDivElement _banner;
  late web.HTMLDivElement _menu;
  late web.HTMLDivElement _content;

  // construye la estructura fija de la página (banner + área de menú/contenido)
  // dentro del elemento [root]
  Views(this.root) {
    // [WARNING] a diferencia de las propiedades ordinarias del DOM (textContent,
    // value...), el setter [innerHTML] de package:web espera un [JSAny], no
    // un [String] de Dart sin procesar - una peculiaridad de su generación vinculada al
    // atributo WebIDL [LegacyNullToEmptyString] del DOM estándar: por lo tanto,
    // siempre debemos convertir con [.toJS].
    root.innerHTML = ''.toJS;

    _banner = _div()..className = 'banner';
    final logo = _div()..className = 'logo';
    logo.innerHTML = _logoSvg.toJS;
    final title = web.document.createElement('h1') as web.HTMLHeadingElement;
    title.textContent = 'Calculate your tax';
    _banner
      ..appendChild(logo)
      ..appendChild(title);

    final body = _div()..className = 'page-body';
    _menu = _div()..className = 'menu';
    _content = _div()..className = 'content';
    body
      ..appendChild(_menu)
      ..appendChild(_content);

    root
      ..appendChild(_banner)
      ..appendChild(body);
  }

  // --------------------------------------------------------------------
  // herramientas de construcción del DOM
  // --------------------------------------------------------------------

  web.HTMLDivElement _div() => web.document.createElement('div') as web.HTMLDivElement;

  void _clearMenu() {
    _menu.innerHTML = ''.toJS;
    _menu.style.display = 'none';
    _content.classList.add('full-width');
  }

  web.HTMLAnchorElement _menuLink(String text, void Function() onClick) {
    final a = web.document.createElement('a') as web.HTMLAnchorElement;
    a.textContent = text;
    a.addEventListener('click', ((web.Event event) => onClick()).toJS);
    return a;
  }

  void _showMenu(List<web.HTMLAnchorElement> links) {
    _menu.innerHTML = ''.toJS;
    _menu.style.display = '';
    _content.classList.remove('full-width');
    for (final link in links) {
      _menu.appendChild(link);
    }
  }

  web.HTMLElement? _errorBanner(String? message) {
    if (message == null) return null;
    final div = _div()..className = 'error';
    div.textContent = message;
    return div;
  }

  // una fila de formulario [label + text/password/number field]
  (web.HTMLDivElement row, web.HTMLInputElement input) _fieldRow(
    String labelText,
    String type,
    String initialValue, {
    String? help,
  }) {
    final row = _div()..className = 'field-row';
    final label = web.document.createElement('label') as web.HTMLLabelElement;
    label.textContent = labelText;
    final field = _div()..className = 'field';
    final input = web.document.createElement('input') as web.HTMLInputElement;
    input.type = type;
    input.value = initialValue;
    if (type == 'number') {
      input.min = '0';
    }
    field.appendChild(input);
    if (help != null) {
      final div = _div()..className = 'help';
      div.textContent = help;
      field.appendChild(div);
    }
    row
      ..appendChild(label)
      ..appendChild(field);
    return (row, input);
  }

  // --------------------------------------------------------------------
  // vista de [authentication]
  // --------------------------------------------------------------------
  void authenticationView(String? error, AuthenticationCallbacks callbacks) {
    _clearMenu();
    _content.innerHTML = ''.toJS;

    final title = _div()
      ..className = 'section-title'
      ..textContent = 'Please authenticate';
    _content.appendChild(title);

    final banner = _errorBanner(error);
    if (banner != null) _content.appendChild(banner);

    final userField = _fieldRow("Username", 'text', 'admin');
    final passwordField = _fieldRow('Password', 'password', '');
    _content
      ..appendChild(userField.$1)
      ..appendChild(passwordField.$1);

    final button = web.document.createElement('button') as web.HTMLButtonElement;
    button.textContent = 'Submit';
    button.addEventListener(
      'click',
      ((web.Event event) {
        callbacks.onSubmit(userField.$2.value.trim(), passwordField.$2.value);
      }).toJS,
    );
    _content.appendChild(button);
  }

  // --------------------------------------------------------------------
  // vista de [tax calculation]
  // --------------------------------------------------------------------
  void calculationView(Simulation? result, String? error, CalculationCallbacks callbacks) {
    _showMenu([
      _menuLink('List of simulations', callbacks.onList),
      _menuLink('End of session', callbacks.onEndSession),
    ]);

    _content.innerHTML = ''.toJS;

    final title = _div()
      ..className = 'section-title'
      ..textContent = 'Fill in the form below and then submit it';
    _content.appendChild(title);

    final banner = _errorBanner(error);
    if (banner != null) _content.appendChild(banner);

    // fila de los radios de [married]
    final marriedRow = _div()..className = 'field-row';
    final marriedLabel = web.document.createElement('label') as web.HTMLLabelElement;
    marriedLabel.textContent = 'Are you married or in a civil partnership?';
    final marriedField = _div()..className = 'field radios';

    final radioYes = web.document.createElement('input') as web.HTMLInputElement;
    radioYes.type = 'radio';
    radioYes.name = 'married';
    radioYes.value = 'yes';
    radioYes.checked = true;
    final labelYes = web.document.createElement('label') as web.HTMLLabelElement;
    labelYes.appendChild(radioYes);
    labelYes.appendChild(web.document.createTextNode(' Yes'));

    final radioNo = web.document.createElement('input') as web.HTMLInputElement;
    radioNo.type = 'radio';
    radioNo.name = 'married';
    radioNo.value = 'no';
    final labelNo = web.document.createElement('label') as web.HTMLLabelElement;
    labelNo.appendChild(radioNo);
    labelNo.appendChild(web.document.createTextNode(' No'));

      ..appendChild(labelYes)
      ..appendChild(labelNo);

      ..appendChild(marriedLabel)
      ..appendChild(marriedField);

        .toJS;
    table.appendChild(thead);

    for (var number = 0; number < simulations.length; number++) {
      final simulation = simulations[number];
      final tr = web.document.createElement('tr') as web.HTMLTableRowElement;
      final ratePercent = (simulation.rate * 100).round();
      tr.innerHTML = ("<td>$number</td>"
              "<td>${simulation.married}</td>"
              "<td>${simulation.children}</td>"
              "<td>${simulation.salary}</td>"
              "<td>${simulation.tax}</td>"
              "<td>${simulation.surcharge}</td>"
              "<td>${simulation.discount}</td>"
              "<td>${simulation.reduction}</td>"
              "<td>$ratePercent %</td>")
          .toJS;
      final tdDelete = web.document.createElement('td') as web.HTMLTableCellElement;
      final deleteLink = web.document.createElement('a') as web.HTMLAnchorElement;
      deleteLink.className = 'delete';
      deleteLink.textContent = 'Delete';
      deleteLink.addEventListener(
        'click',
        ((web.Event event) => callbacks.onDelete(number)).toJS,
      );
      tdDelete.appendChild(deleteLink);
      tr.appendChild(tdDelete);
      tbody.appendChild(tr);
    }
    table.appendChild(tbody);
    _content.appendChild(table);
  }

// Porta AppHtml.ts: el controlador de la aplicación HTML. Orquesta las
// llamadas al servidor (capa [dao], dao3.dart), los cálculos
// (capa [business], business.dart) y la visualización de las vistas (capa [views],
// views.dart).
//
// Como main3.dart, este cliente llama al servidor NestJS solo para tres
// acciones: [init-session], [authenticate-user] y [get-admindata].
// Una vez recuperados los datos fiscales (tasas, topes...) con
// [get-admindata], es la capa [business] la que calcula el impuesto en el
// navegador, sin nuevas llamadas de red. La lista de simulaciones también se
// mantiene solo en el navegador (campo [simulations]),
// exactamente como lo hace main3.dart con su variable local
// [simulations] (`simulations.add(...)`, `simulations.removeAt(...)`).
import 'dart:js_interop';
import 'package:http/browser_client.dart';
import 'dao3.dart';
import 'business.dart';
import 'simulation.dart';
import 'views.dart';
import 'package:web/web.dart' as web;

class AppHtml {
  final Dao3 dao;
  final Views views;
  // capa [business]: solo existe una vez recuperados los datos fiscales
  // (después de una autenticación exitosa) - ver [_initBusiness]. Un
  // campo NULABLE (Business?), no un campo diferido ([late]): a diferencia de
  // Views.ts, donde [business?: Business] simplemente permanece "undefined" mientras
  // no se le asigne un valor, un campo [late] de Dart lanzaría un error si se
  // LEYERA antes de la asignación (que es precisamente lo que hace [_endSession] cuando
  // lo reinicia) - por lo tanto, el tipo nulable es la elección correcta aquí, no
  // solo una cuestión de estilo.
  Business? _business;
  // lista de las simulaciones ya calculadas, mantenida en el navegador
  List<Simulation> _simulations = [];

  // [difference with TypeScript] AppHtml.ts configura una instancia GLOBAL de axios
  // (axios.defaults.timeout/baseURL/withCredentials) y luego se la entrega
  // al Dao. Aquí, [BrowserClient] (package:http/browser_client.dart, ya
  // visto en main3.dart) lleva el equivalente de
  // "axios.defaults.withCredentials = true"; no hay un equivalente directo de un
  // "timeout global" en http.Client - se aplicaría caso
  // por caso con `.timeout(Duration(...))` en cada llamada, como en el capítulo
  // de [http] (dart_fetch_01.dart).
  AppHtml()
      : dao = Dao3(
          BrowserClient()..withCredentials = true,
          'http://localhost:3000',
        ),
        views = Views(web.document.getElementById('app') as web.HTMLElement);

  // punto de entrada de la aplicación
  Future<void> start() async {
    try {
      // inicio de sesión - obligatorio antes de cualquier otra acción (ver main.php)
      final response = await dao.initSession() as Map<String, dynamic>;
      if (response['status'] != 700) {
        views.authenticationView(
          _formatError(response['response']),
          (onSubmit: (user, password) => _authenticate(user, password)),
        );
        return;
      }
    } catch (error) {
      views.authenticationView(
        "Unable to contact the server ($error)",
        (onSubmit: (user, password) => _authenticate(user, password)),
      );
      return;
    }
    // sesión inicializada: mostramos la autenticación
    _showAuthentication();
  }

  // --------------------------------------------------------------------
  // vista de [authentication]
  // --------------------------------------------------------------------
  void _showAuthentication([String? error]) {
    views.authenticationView(
      error,
      (onSubmit: (user, password) => _authenticate(user, password)),
    );
  }

  Future<void> _authenticate(String user, String password) async {
    try {
      final response = await dao.authenticateUser(user, password)
          as Map<String, dynamic>;
      if (response['status'] == 200) {
        // autenticación exitosa: como en main3.dart, ahora recuperamos,
        // de una vez por todas, los datos fiscales
        // que necesita la capa [business]
        await _initBusiness();
      } else {
        // fallo (login/contraseña incorrectos, o parámetros faltantes)
        _showAuthentication(_formatError(response['response']));
      }
    } catch (error) {
      _showAuthentication("Unable to contact the server ($error)");
    }
  }

  // recupera los datos de la administración fiscal e instancia la
  // capa [business] con estos datos - una sola llamada al servidor para toda la
  // sesión, exactamente como main3.dart
  Future<void> _initBusiness() async {
    try {
      final response = await dao.getAdminData() as Map<String, dynamic>;
      if (response['status'] == 1000) {
        _business = Business(response['response'] as Map<String, dynamic>);
        // nueva sesión de trabajo: partimos de nuevo de una lista vacía
        _simulations = [];
        _showCalculation();
      } else {
        _showAuthentication(_formatError(response['response']));
      }
    } catch (error) {
      _showAuthentication("Unable to contact the server ($error)");
    }
  }

  // --------------------------------------------------------------------
  // vista de [tax calculation]
  // --------------------------------------------------------------------
  void _showCalculation([Simulation? result, String? error]) {
    views.calculationView(
      result,
      error,
      (
        onSubmit: (married, children, salary) =>
            _calculate(married, children, salary),
        onList: () => _showList(),
        onEndSession: () => _endSession(),
      ),
    );
  }

  // cálculo del impuesto realizado íntegramente en el navegador (capa [business]):
  // sin llamada al servidor, a diferencia de la primera versión
  // de este cliente (http client 1 / http client 2)
  void _calculate(String married, int children, int salary) {
    // _business necesariamente ha sido inicializado: solo llegamos a la vista de [calculation]
    // después de _initBusiness (por lo que el [!] es seguro aquí, como el [!] de TypeScript
    // en [this.business!])
    final result = _business!.calculateTax(married, children, salary);
    // [difference with TypeScript] Views.ts construye la simulación con un
    // simple spread de objeto: `{ married, children, salary, ...result }`.
    // Aquí, [Simulation] es un RECORD (simulation.dart), no un Map: un
    // record no puede "completarse" con el spread de un Map, y
    // sus campos están tipados (num, int...) mientras que
    // [result], devuelto por business.dart, es un Map sin tipar cuyas claves
    // simplemente TIENEN los mismos nombres ('tax', 'surcharge'..., ver business.dart). Por lo tanto,
    // reconstruimos el record campo por campo - un poco más verboso
    // que un spread, pero completamente verificado por el compilador (un campo olvidado
    // o con tipo incorrecto es un error de compilación, no una sorpresa en
    // tiempo de ejecución).
    final Simulation simulation = (
      married: married,
      children: children,
      salary: salary,
      tax: result['tax'] as num,
      surcharge: result['surcharge'] as num,
      discount: result['discount'] as num,
      reduction: result['reduction'] as num,
      rate: result['rate'] as num,
    );
    // almacenamiento en el navegador (como `simulations.add(...)` en
    // main3.dart)
    _simulations.add(simulation);
    _showCalculation(simulation);
  }

  // --------------------------------------------------------------------
  // vista de [list of simulations]
  // --------------------------------------------------------------------
  // ya no hay llamadas al servidor aquí: la lista ya está completamente en
  // [_simulations]
  void _showList([String? error]) {
    views.listView(
      _simulations,
      error,
      (
        onDelete: (number) => _deleteSimulation(number),
        onCalculation: () => _showCalculation(),
        onEndSession: () => _endSession(),
      ),
    );
  }

  void _deleteSimulation(int number) {
    // eliminación local de [_simulations], como
    // `simulations.removeAt(number)` en main3.dart - sigue sin haber ninguna llamada
    // al servidor
    _simulations.removeAt(number);
    _showList();
  }

  // --------------------------------------------------------------------
  // fin de sesión
  // --------------------------------------------------------------------
  void _endSession() {
    // fin de sesión solo del lado del cliente: olvidamos la capa [business]
    // (y por lo tanto los datos fiscales) y las simulaciones ya calculadas, y luego
    // volvemos a la pantalla de autenticación. Este cliente no necesita
    // llamar al servidor para esto.
    _business = null;
    _simulations = [];
    _showAuthentication();
  }

  // --------------------------------------------------------------------
  // formatea el campo [response] de una respuesta de error del servidor, que
  // es una cadena o una lista de cadenas (ver los controladores PHP)
  // --------------------------------------------------------------------
  String _formatError(Object? response) {
    if (response is List) {
      return response.join(' ; ');
    }
    return '$response';
  }
}

    • líneas 46–51: [AppHtml() : dao = Dao3(BrowserClient()..withCredentials = true, ...), views = Views(...)]: construcción del DAO y de las VISTAS en una LISTA DE INICIALIZADORES - el mismo concepto que el constructor de TypeScript, con la sintaxis propia de Dart [: field1 = ..., field2 = ...].
    • Línea 34: [Business? _business;]: un campo NULABLE, donde AppHtml.ts usaba antes [business?: Business] - el mismo concepto («aún no inicializado»), con el mismo operador [!] para confirmar que efectivamente tiene un valor en un punto específico del código.
    • Líneas 158–162: [final Simulation simulation = (married: married, ..., tax: result['tax'] as num, ...);]: a diferencia del simple spread [{ married, children, salary, ...result }] de AppHtml.ts, un REGISTRO no se puede completar mediante un spread a partir de un [Map]; por lo tanto, el registro se reconstruye CAMPO POR CAMPO, lo cual es un poco más extenso pero está totalmente validado por el compilador.
    • Líneas 229–233: [web.window.addEventListener('DOMContentLoaded', ((web.Event event) { AppHtml().start(); }).toJS);]: el mismo punto de entrada que en AppHtml.ts, con la misma conversión de callback ([.toJS]) que en views.dart.

    6.6. Conclusión

    Los cuatro clientes de este capítulo ilustran, con Dart, exactamente la misma progresión que con TypeScript: del procesamiento del lado del servidor al procesamiento del lado del cliente, y luego del script CLI al cliente web completo. Las diferencias clave que conviene retener son el seguimiento manual de la cookie de sesión (necesario en CLI, innecesario en un navegador), la conversión [.toJS] impuesta por [dart:js_interop] para cruzar la frontera entre Dart y JavaScript en las vistas, y la ausencia total de polyfills en la compilación web—una clara ventaja de la cadena de herramientas de Dart frente al pipeline webpack/babel.
